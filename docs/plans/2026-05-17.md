# FinMind Plugin Implementation Plan

> **Historical note (2026-05-18):** This plan was executed against a workspace
> layout of `FinMind/plugin/{knowledge,chatgpt,mcp,install}/`. After Phase B
> the contents were relocated into this dedicated repo (`FinMind-MCP/`) — the
> file paths below are kept for traceability, see `docs/spec.md` for the
> current canonical layout.

> **For agentic workers:** Each Task below is a self-contained agent brief. Tasks within the same Phase are independent and run in parallel via background `Agent` dispatch. Phases run sequentially.

**Goal:** Build FinMind Plugin (per `docs/spec.md`) covering ChatGPT Custom GPT + MCP server, sharing one knowledge pack.

**Architecture:** Single source-of-truth markdown knowledge pack → two distributions: (A) ChatGPT Action with OpenAPI YAML + compiled instructions, (B) Python MCP server using official `mcp` SDK with stdio transport.

**Tech Stack:**
- Python 3.10+ (matches FinMind repo)
- `mcp` Python SDK (official MCP server)
- `httpx` (async HTTP to FinMind API)
- `pytest` + `pytest-asyncio` + `respx` (HTTP mocking)
- `pyyaml` (OpenAPI generation)

**Scope boundaries:**
- **In scope (this plan):** All code, schemas, markdown, tests that can be authored & run locally
- **Out of scope (user does):** OpenAI Custom GPT setup, GPT Store submission, PyPI/npm publishing, `mcp.finmindtrade.com` deployment, cross-platform UI smoke testing

2. **Implement `client.py`:**

```python
import os
import httpx
from typing import Optional
from .errors import (
    AuthenticationError, PaymentRequiredError, EmptyDataError,
    RateLimitError, UpstreamError,
)

BASE_URL = "https://api.finmindtrade.com"

class FinMindClient:
    def __init__(self, token: Optional[str] = None, base_url: str = BASE_URL):
        self.token = token or os.environ.get("FINMIND_TOKEN")
        if not self.token:
            raise AuthenticationError("FINMIND_TOKEN not set")
        self.base_url = base_url

    async def query_dataset(self, dataset: str, data_id: Optional[str] = None,
                            start_date: Optional[str] = None,
                            end_date: Optional[str] = None) -> list[dict]:
        params = {"dataset": dataset, "token": self.token}
        if data_id: params["data_id"] = data_id
        if start_date: params["start_date"] = start_date
        if end_date: params["end_date"] = end_date

        async with httpx.AsyncClient(timeout=30.0) as c:
            r = await c.get(f"{self.base_url}/v4/data", params=params)
        self._raise_for_status(r)
        data = r.json().get("data", [])
        if not data:
            raise EmptyDataError(f"no data for {dataset} data_id={data_id} start_date={start_date}")
        return data

    async def list_datasets(self) -> list[str]:
        async with httpx.AsyncClient(timeout=30.0) as c:
            r = await c.get(f"{self.base_url}/v4/datalist", params={"token": self.token})
        self._raise_for_status(r)
        return r.json().get("data", [])

    @staticmethod
    def _raise_for_status(r: httpx.Response):
        if r.status_code == 401: raise AuthenticationError(r.text)
        if r.status_code == 402: raise PaymentRequiredError(r.text)
        if r.status_code == 429: raise RateLimitError(r.text)
        if r.status_code >= 500: raise UpstreamError(r.text)
        r.raise_for_status()
```
